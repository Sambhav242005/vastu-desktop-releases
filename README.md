# Vastu Grid for Windows

Download the latest published Windows installer from [Releases](https://github.com/Sambhav242005/vastu-desktop-releases/releases).

Install the EXE once. The app checks for updates when online, downloads updates in the background, and offers **Restart to update**.

Projects, imported plans, exports and backups live in **Documents ? Vastu**. Application updates preserve this folder. Core features work offline; maps and online services require an internet connection.

This repository contains download artifacts only. Application source is maintained separately.

The first Windows build is unsigned, so Windows may display an unknown-publisher warning.
