# Vastu Grid 1.1.17 for Windows

- Load real Copernicus terrain online directly in Windows, without setting up an app server or importing DEM files.
- View elevation immediately; small plots show when source spacing cannot resolve local slope.
- Image editing now uses the same Vastu grid, bearing, colors and opacity as the final preview.
- Fixed rotated-image gestures and entrance anchoring while preserving saved projects.

Internet is required for terrain. Copernicus GLO-30 has roughly 30 m source spacing and is not a surveyed grade. The Windows installer remains unsigned.
